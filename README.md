# Sistema de Gestión de Coworking - Backend XP & BDD

Este proyecto implementa la API backend para un sistema de reservas de salas de coworking aplicando las metodologías ágiles **Extreme Programming (XP)** y **Behavior-Driven Development (BDD)**.

## 🚀 Arquitectura y Tecnologías

- **Lenguaje:** TypeScript (Modo Estricto)
- **Framework Web:** Express.js
- **Testing & BDD:** Cucumber.js + Supertest
- **Integración Continua:** GitHub Actions

## 🛠️ Instalación y Ejecución

1. **Clonar el repositorio e instalar dependencias:**
   ```bash
   npm install
   ```
